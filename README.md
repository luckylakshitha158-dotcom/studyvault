# 📚 StudyVault — RRB ALP & SSC Exam Prep

Your personal study companion with syllabus tracker, resource manager, and progress tracking.

## 🚀 Deploy to Vercel (Free) in 3 Steps

### Step 1 — Create Vercel Account
Go to https://vercel.com and sign up free (use GitHub login for easiest setup)

### Step 2 — Deploy
**Option A (Drag & Drop — Easiest):**
1. Go to https://vercel.com/new
2. Click "Browse" and upload this entire `studyvault` folder
3. Click Deploy — done in ~1 minute!

**Option B (Via GitHub):**
1. Upload this folder to a GitHub repo
2. Connect repo on vercel.com/new
3. Auto-deploys on every change

### Step 3 — Install on Phone as App Icon
1. Open the Vercel link on your phone browser (Chrome / Safari)
2. **Android:** Tap the 3-dot menu → "Add to Home Screen" → Done ✅
3. **iPhone:** Tap the Share icon → "Add to Home Screen" → Done ✅

The app will appear as an icon on your phone — just like a real app!

## 💻 Run Locally
```bash
npm install
npm start
```
Then open http://localhost:3000

## ✨ Features
- RRB ALP: CBT1, CBT2, CBT3 syllabus
- SSC: Tier 1, Tier 2 syllabus
- Upload PDFs, add links, write notes per topic
- Progress tracker with checkboxes
- Search topics and resources
- Dark / Light theme toggle
- All data saved locally on your device
